CityPulse Telegram Bot 🏙️
A lightweight, asynchronous Telegram bot built with Python that provides users with real-time weather data and quick Wikipedia summaries. Developed to practice API integration, asynchronous programming (asyncio), and JSON parsing.
🚀 Features
* Real-time Weather: Users can fetch current weather conditions for any city globally. Uses the wttr.in API to parse JSON data.
* Knowledge Base: Integrated with the Wikipedia API to provide concise, two-sentence summaries on any topic.
* Asynchronous Handling: Built using the python-telegram-bot library (v20+) for non-blocking message processing.
* Error Handling: Gracefully handles invalid inputs, missing cities, and broad Wikipedia queries without crashing.
🛠️ Tech Stack
* Language: Python 3.9+
* Libraries: python-telegram-bot, requests, wikipedia, nest_asyncio
* Concepts: REST APIs, JSON Parsing, Asynchronous Programming, Object-Oriented Programming (OOP) concepts.
